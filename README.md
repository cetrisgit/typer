# Typer - Split Keyboard Typing Practice

A web-based typing practice application designed specifically for split/ergonomic keyboards. Practice and improve your typing speed and accuracy with real-time feedback.

## Features

- **Real-time Statistics**: Track your Words Per Minute (WPM), accuracy, and time
- **Visual Keyboard**: Split keyboard layout showing which hand types which keys
- **Key Highlighting**: Visual feedback showing the next key to press
- **Multiple Difficulty Levels**: Easy, Medium, and Hard text samples
- **Accuracy Tracking**: Real-time visual feedback for correct and incorrect characters

## Getting Started

### Installation

1. Clone this repository
2. Open `index.html` in your web browser

That's it! No build process or dependencies required.

### Usage

1. Open `index.html` in your browser
2. Start typing the displayed text in the input field
3. The timer starts automatically when you begin typing
4. Watch your WPM and accuracy update in real-time
5. The visual keyboard highlights the next key to press
6. Complete the text to see your final score

### Controls

- **New Text**: Load a new random text sample
- **Reset**: Clear current progress and start over
- **Difficulty Dropdown**: Choose between Easy, Medium, and Hard difficulty levels

## Split Keyboard Layout

The app displays a visual representation of a split keyboard layout:

- **Left Hand**: Q-W-E-R-T, A-S-D-F-G, Z-X-C-V-B
- **Right Hand**: Y-U-I-O-P, H-J-K-L-;, N-M-,-.-/

Keys are highlighted as you type, helping you learn proper finger placement for split keyboards.

## Tips for Practice

1. Focus on accuracy first, speed will come with practice
2. Keep your eyes on the text, not the keyboard
3. Use the visual keyboard guide to learn key positions
4. Practice regularly for 10-15 minutes daily
5. Gradually increase difficulty as you improve
